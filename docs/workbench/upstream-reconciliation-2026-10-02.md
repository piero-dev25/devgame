## Why the product tip, not `main`

`workbench/upstream-20260806` is `main` plus 29 commits (12–15 Aug) that never
went through a PR: the generation service (increments 1, 2a, 2b.1), the #155
fix that made every DevGame MCP tool reachable from in-app agents, and the
isolation that stops in-app agents inheriting the owner's personal MCP
servers. The owner docket records D1/D3 approvals, and the commits record live
acceptance. Basing on `main` would have dropped live-proven fixes. Cost: 8
extra conflicted files, all on the MCP/provider seam already in conflict.
These commits get their first review through this branch.

## Decisions that span files

- **Effect rc.115.** `Schema.TaggedErrorClass` → `Schema.TaggedError` and the other renames applied to all DevGame code.
- **MCP.** Upstream `McpServer.toolkit` registers every toolkit (Preview, PullRequests, Device, Generation). `generation` joins the upstream `McpCapability` union; sessions are granted `pull-requests` and `generation`, and `preview` stays gated by upstream settings. The startup guard that refuses tool schemas without `type: "object"` (#155) stays, with its production-topology test.
- **Claude provider.** The SDK env combines upstream `withAgentDeviceEnvironment` with DevGame's `ENABLE_CLAUDEAI_MCP_SERVERS=false` and `strictMcpConfig`.
- **Migrations.** DevGame keeps its id space: fork 36/37 are spaces, and upstream migrations are shifted +2 (files renamed to 041–056). A ledger guard compares recorded `(id, name)` rows with the manifest and refuses to start on a mismatch, so a database migrated by stock T3 Code is never silently skipped or mutated. Storage isolation (#98: DevGame using its own data directory instead of `~/.t3`) remains the real fix and is an owner decision.
- **Editor selection and engine state.** Ported to upstream composer context records (`editor-selection`, `engine-state`), so every send path carries them. Trailing-tag extraction stays as a read path for older messages.
- **Web shell.** Thread routes mount `ChatDock` inside upstream's hoisted `ThreadRouteView`, so the dock now also survives draft promotion. `/settings*`, `/usage` and `/pull-requests` render in `AppSidebarLayout`.
- **Identity.** New upstream return URLs, the Codex handoff, the Linux desktop id, the model manifest and release endpoints use DevGame identity (`devgame://`, `devgame-dev://`, `com.devgame.*`). `t3 triage` is unregistered until its playbook is rebranded.
- **Dead code.** `captureTabScreenshotDataUrl` is removed end to end, since its only consumer was deleted earlier by owner ruling.
