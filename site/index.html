DevGame

An agent workbench for game developers. Run coding agents against your project, with the objects you have selected in Unity, Unreal or Godot already in the chat box before you type.

Get DevGame Source on GitHub

macOS builds are being prepared. The source is available now and builds from a clone.

Editor presence

Select a prefab in Unity, a node in Godot, an actor in Unreal — it turns up as a chip in the composer straight away, and travels with the message you send. No copying paths, no describing what you mean.

Plugins are included for Unity, Unreal and Godot. Unreal ships as an Editor Python plugin and Godot as a GDScript addon, so neither needs a compile toolchain to install.

It runs on your machine

DevGame drives the agents you already pay for — Claude Code, Codex, Cursor, Grok, OpenCode — using your own subscriptions. The backend runs locally, on your project, on your machine.

You can use DevGame from a browser or a phone, but that is a client pairing to the backend on your own computer. There is no hosted version that runs your project for you, and your code is not uploaded anywhere.

Open source

DevGame is MIT-licensed and developed in the open. If it ever goes a direction you dislike, you have everything you need to fork it.
